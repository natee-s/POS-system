# SmartPOS - Modern Point of Sale System

SmartPOS is a fast, responsive, and user-friendly Point of Sale (POS) application built for modern businesses. It allows users to browse food items, manage a shopping cart, and process orders seamlessly on any device.



## 🚀 Live Demo
Check out the live project here: (https://pos-system-gilt-delta.vercel.app/)

## ✨ Key Features

* **Responsive Design:** Fully optimized for both Desktop and Mobile. Includes a mobile-friendly Hamburger Menu and a Floating Cart button.
* **Interactive Shopping Cart:** * Add items to your order with a custom popup.
    * Update quantities (+/-) directly in the cart.
    * Remove items with a single click.
* **Smart Search & Filtering:** Filter products by category or use the real-time search bar to find exactly what you need.
* **Checkout System:** A smooth checkout flow with a success notification and automatic cart clearing.
* **Auto-Calculations:** Real-time calculation of sub-totals and grand totals.

## 🛠️ Tech Stack

* **React:** For building the user interface and managing state.
* **Tailwind CSS:** For modern, utility-first styling and responsive layouts.
* **Vite:** For a lightning-fast development environment.
* **React Icons:** For clean and consistent UI icons.
* **Vercel:** For hosting and continuous deployment.
